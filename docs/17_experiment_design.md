# 17. 테스트 거래 실험 설계

## 1. 실험의 목적

30일 테스트 거래는 매출만 보기 위한 것이 아니다. 목적은 **매칭 가설을 검증하는 것**이다.

```text
가설:
이 제조사의 이 제품은 이 유통사와 이 판매사를 통해
이 국가·채널·트렌드 문장으로 판매될 가능성이 높다.
```

---

## 2. 실험 단위

```text
제조사 × 제품 × 유통사 × 판매사 × 국가 × 채널 × 트렌드
```

예:

```text
ABC코스메틱 × 노워시 퍼퓸 헤어오일 × Tokyo Beauty Distribution × Tokyo Beauty Select × JP × Instagram/BASE × 향·헤어 루틴
```

---

## 3. 30일 실험 구조

### 1주차: 준비

```text
제품 스펙 검증
샘플 확보
가격/마진 계산
상세페이지 현지화
리스크 체크
판매사 콘텐츠 브리프 작성
```

### 2주차: 콘텐츠/상품 노출

```text
판매 채널 등록
KOC/콘텐츠 발행
초기 반응 수집
댓글/질문 분류
```

### 3주차: 판매/전환 측정

```text
가격 테스트
상세페이지 수정
리뷰 확보
장바구니/문의/주문 추적
```

### 4주차: 본계약 판단

```text
판매 결과 분석
마진 계산
반품/CS 점검
재발주 가능성 판단
본계약/중단/재테스트 결정
```

---

## 4. 측정 지표

| 영역 | 지표 |
|---|---|
| 콘텐츠 | 노출, 저장, 댓글, 공유, 클릭 |
| 판매 | 주문 수, 전환율, 객단가, 매출 |
| 경제성 | 공급가, 판매가, 수수료, 물류비, 실마진 |
| 운영 | 배송 리드타임, CS 수, 반품률 |
| 관계 | 제조사 응답 속도, 유통사 협업성, 판매사 실행력 |
| 판단 | 본계약 가능성, 재발주 가능성, 확장 가능성 |

---

## 5. 성공/실패 판정

### 성공

```text
판매 전환 발생
댓글/리뷰 품질 양호
실마진 양수
반품/CS 관리 가능
제조사·유통사·판매사 협업성 양호
재발주 의향 있음
```

### 조건부 성공

```text
반응은 좋지만 가격 조정 필요
콘텐츠 반응은 좋지만 전환 약함
유통사는 맞지만 판매사 교체 필요
제품은 맞지만 패키지/표기 수정 필요
```

### 실패

```text
가격 저항 강함
인증/통관 리스크 큼
MOQ 불일치
판매사 고객층과 부적합
클레임/반품 리스크 큼
```
