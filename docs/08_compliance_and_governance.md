# 08. 컴플라이언스와 데이터 거버넌스

## 1. 기본 원칙

데이터 수집은 장기 사업 자산을 만드는 행위다. 단기적으로 많이 긁어오는 것보다 **지속 가능하고 신뢰 가능한 방식**이 중요하다.

```text
공식 API 우선
권한 기반 데이터 우선
robots.txt와 이용약관 확인
개인정보 최소 수집
출처·수집일·신뢰도 기록
민감정보 분리 보관
```

---

## 2. 웹 수집 원칙

```text
robots.txt 확인
사이트맵 확인
요청 빈도 제한
로그인·권한 우회 금지
개인정보 불필요 수집 금지
원문 전체 복제보다 필요한 메타데이터 중심 저장
출처 URL 기록
```

제조사 홈페이지와 유통사 홈페이지는 공개된 B2B 정보 중심으로 수집한다.

---

## 3. 플랫폼 데이터 원칙

```text
공식 API 사용
판매자/광고주 권한 기반 데이터 사용
협업 플랫폼 데이터 사용
수동 리서치 데이터는 낮은 신뢰도로 저장
비인가 대량 수집 지양
```

샤오홍수·더우인·Instagram·TikTok 등 소셜 플랫폼은 정책 변화가 잦으므로 데이터 사용 범위를 별도 관리한다.

---

## 4. 개인정보 최소화

수집하지 않는 것을 기본으로 한다.

```text
불필요한 개인 전화번호
개인 이메일
개인 주소
개인 식별 가능한 SNS 비공개 정보
민감정보
```

담당자 정보가 필요한 경우에는 거래 목적, 동의, 보관 기간, 접근 권한을 명확히 한다.

---

## 5. 데이터 출처 관리

모든 데이터에는 다음 필드를 둔다.

```text
source_id
source_name
source_url
source_type
collected_at
license_or_terms
confidence_level
verified_by
verified_at
```

---

## 6. 신뢰도 관리

```text
레벨 1: 공개 웹 관찰
레벨 2: 플랫폼 공개 페이지
레벨 3: 정부·공공 API
레벨 4: 업체 제출 자료
레벨 5: 플로머스 검수 자료
레벨 6: 테스트 거래 결과
레벨 7: 반복 거래 결과
```

검색과 추천은 신뢰도 레벨을 함께 보여줘야 한다.

---

## 7. 추천 설명 책임

LLM 기반 검색 결과는 반드시 다음을 포함해야 한다.

```text
추천 대상
추천 이유
근거 데이터
리스크
확인 필요 사항
다음 액션
```

근거 없이 단정적인 추천을 하지 않는다.
