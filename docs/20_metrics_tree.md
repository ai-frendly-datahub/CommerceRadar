# 20. 지표 트리

## 1. North Star Metric

플로머스의 핵심 지표는 단순 수집 데이터 수가 아니다.

```text
검증된 매칭에서 발생한 반복 거래액
```

보조 North Star:

```text
30일 테스트 후 본계약 또는 재발주로 전환된 조합 수
```

---

## 2. 입력 지표

```text
제조사 수집 수
제품 상세 수집 수
유통사 포트폴리오 수집 수
판매사 포트폴리오 수집 수
트렌드 키워드 수
근거 레코드 수
검수 완료 비율
```

## 9. 경고 지표

```text
데이터는 많지만 미팅 전환이 낮음
조합 점수는 높지만 운영자 부적합 피드백이 많음
테스트 판매는 되지만 실마진이 낮음
본계약은 되지만 재발주가 없음
거래 실패 사유가 기록되지 않음
```

경고 지표가 보이면 데이터 수집을 늘리기보다 매칭 기준과 실험 설계를 먼저 수정해야 한다.
