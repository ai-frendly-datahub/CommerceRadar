# 19. 리스크 레지스터

## 1. 데이터 수집 리스크

| 리스크 | 설명 | 대응 |
|---|---|---|
| 사이트 약관 위반 | 플랫폼/웹사이트의 자동 수집 제한 | 공식 API, 권한 기반 연동, robots.txt 확인 |
| 과도한 요청 | 대상 서버 부하 | rate limit, 캐시, 증분 수집 |
| 비공개 데이터 수집 | 접근 권한 없는 데이터 수집 | 공개/동의/공식 API만 사용 |
| 저작권 | 상세페이지 이미지/문구 재사용 | 원문 저장 최소화, 요약/메타데이터 중심, 출처 보존 |

참고:
- Google robots.txt 가이드: https://developers.google.com/search/docs/crawling-indexing/robots/intro

## 2. 개인정보/영업정보 리스크

| 리스크 | 설명 | 대응 |
|---|---|---|
| 담당자 개인정보 | 이메일/전화/명함 데이터 | 최소 수집, 목적 제한, 접근권한 관리 |
| 거래 조건 유출 | 공급가, MOQ, 정산 조건 | 권한 분리, 암호화, 감사 로그 |
| 고객 데이터 | 판매사 주문/리뷰/고객 정보 | 익명화, 집계 데이터 우선 |

---

## 3. 추천/매칭 리스크

| 리스크 | 설명 | 대응 |
|---|---|---|
| 근거 없는 추천 | LLM 환각 또는 약한 추론 | Evidence 필수, 신뢰도 표시 |
| 오래된 데이터 | 폐업/포트폴리오 변경 | 최신성 점수, 재검증 큐 |
| 편향된 점수 | 일부 데이터 소스 과대반영 | 점수 설명 가능성, 운영자 피드백 |
| 거래 실패 책임 | 추천 후 실패 시 신뢰 하락 | 조건부 추천, 테스트 거래 우선 |

## 4. 상품/규제 리스크

| 리스크 | 설명 | 대응 |
|---|---|---|
| 인증 필요 | KC, 화장품, 식품, 의료기기 등 | 카테고리별 인증 체크리스트 |
| IP/상표 | 굿즈, 캐릭터, 브랜드 | KIPRIS/J-PlatPat/상표 확인 |
| 통관 제한 | 국가별 수입 규제 | HS코드와 규제 DB 연결 |
| 표현 리스크 | 효능·의학적 표현 | 상세페이지 금지 표현 룰 |

## 5. 사업 리스크

| 리스크 | 설명 | 대응 |
|---|---|---|
| 단순 브로커화 | 연락처 소개로 끝남 | 테스트 거래와 운영 수수료까지 연결 |
| 직접 거래 우회 | 소개 후 플로머스 배제 | 거래 관리, 정산, 리포트, 계약 템플릿 제공 |
| 데이터 수집만 하고 매출 없음 | 리서치 회사화 | 유료 진단/테스트 패키지부터 판매 |
| 범위 과다 | 국가/카테고리 확장 과속 | 초기 카테고리 3개 제한 |

## 6. 우선 대응 항목

```text
1. 데이터 출처와 신뢰도 필드 필수화
2. 공식 API/권한 기반 데이터 우선
3. 근거 없는 추천 금지
4. 인증/IP/통관 리스크 필드 의무화
5. 거래 결과 데이터 접근권한 분리
```
