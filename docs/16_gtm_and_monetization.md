# 16. GTM과 수익화 전략

## 1. 포지셔닝

플로머스는 “해외 유통 대행사”가 아니라 **한·중·일 B2B 커머스 매칭 인프라**다.

```text
제조사는 맞는 판로를 찾고,
유통사는 팔릴 상품을 찾고,
판매사는 트렌드에 맞는 공급처를 찾는다.
플로머스는 이 셋의 조합을 데이터로 설계한다.
```

---

## 2. 초기 고객

### 제조사

```text
K-뷰티/헤어/향 제조사
소형 생활용품 제조사
캐릭터/굿즈 제조사
펫 라이프스타일 제조사
```

구매 이유:

```text
해외 판로를 찾고 싶다.
유통사를 직접 찾기 어렵다.
광고비를 태우기 전에 시장성을 검증하고 싶다.
```

### 유통사

```text
일본 소형 뷰티/생활용품 유통사
한국 온라인 유통사
중국 크로스보더/샤오홍수 운영사
```

구매 이유:

```text
검증된 상품 소싱이 필요하다.
마진과 조건이 맞는 제조사를 찾고 싶다.
```

### 판매사

```text
Instagram/BASE 판매사
스마트스토어/자사몰 운영사
샤오홍수 KOC 운영사
라이브커머스사
```

구매 이유:

```text
트렌드에 맞는 상품이 필요하다.
안정적인 공급처와 위탁 조건이 필요하다.
```

## 3. 상품 패키지

### 3.1 판로 진단 리포트

```text
가격: 50만~300만 원
내용: 제품 스펙 분석, 국가/채널 적합도, 경쟁 가격대, 리스크, 추천 액션
목적: 유료 진입 상품
```

### 3.2 매칭 후보 리포트

```text
가격: 100만~500만 원
내용: 제조사/유통사/판매사 후보 5~10개, 점수, 근거, 미팅 주선
목적: 실제 거래 기회 생성
```

### 3.3 30일 테스트 거래 패키지

```text
가격: 300만~2,000만 원 + 실비
내용: 샘플, 상세페이지, KOC/판매 테스트, 리포트, 본계약 판단
목적: 플로머스 고유 거래 결과 데이터 확보
```

### 3.4 거래 운영 수수료

```text
가격: 거래액의 3~7% 또는 월 운영비
내용: 주문, 정산, 클레임, 재발주, 성과 리포트
목적: 반복 매출
```

### 3.5 데이터/SaaS

```text
가격: 월 10만~300만 원 또는 구축비
내용: 검증 상품 리스트, 트렌드 리포트, 매칭 검색, 거래 관리
목적: 장기 플랫폼화
```

## 4. 영업 메시지

제조사용:

```text
“해외 유통사를 무작위로 소개하지 않습니다.
귀사 제품 스펙과 국가·채널·판매사 데이터를 연결해
가장 성공 가능성이 높은 판로부터 30일 테스트합니다.”
```

유통사용:

```text
“상품 리스트가 아니라, 귀사 포트폴리오·위치·거래 방식에 맞는
검증 제조사와 제품을 추천합니다.”
```

판매사용:

```text
“콘텐츠로 팔 수 있고 공급이 안정적이며
마진이 남는 상품을 트렌드 기준으로 연결합니다.”
```

## 5. 퍼널 KPI

| 단계 | KPI |
|---|---|
| 리드 발굴 | 수집 업체 수, 유효 업체 비율 |
| 진단 | 유료 진단 전환율, 리포트 만족도 |
| 매칭 | 미팅 성사율, 샘플 발송률 |
| 테스트 | 30일 테스트 착수율, 판매/댓글/리뷰 데이터 |
| 계약 | 본계약 전환율, 첫 발주액 |
| 반복 | 재발주율, 월 거래액, 거래 수수료 |

## 6. 90일 GTM

```text
1~30일:
- 카테고리 3개 선정
- 제조사 100개, 유통사 50개, 판매사 50개 수집
- 판로 진단 리포트 10건 판매

31~60일:
- 30일 테스트 패키지 3건 착수
- 조합 카드 100개 생성
- 실제 거래 결과 스키마 확정

61~90일:
- 본계약 1~3건 목표
- 거래 운영 수수료 모델 적용
- 내부 검색 엔진 v1 출시
```

## 7. 핵심 원칙

```text
초기에는 플랫폼보다 서비스로 판다.
서비스 과정에서 데이터를 만든다.
데이터가 쌓이면 검색과 추천을 제품화한다.
제품화 이후 SaaS와 수수료 모델로 확장한다.
```
