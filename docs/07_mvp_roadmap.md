# 07. MVP 로드맵

## 1. MVP 목표

30일 안에 완성해야 할 것은 거대한 플랫폼이 아니라 다음 세 가지다.

```text
1. 제조사 제품 상세/스펙을 구조화한다.
2. 유통사 포트폴리오/위치를 구조화한다.
3. 판매사 포트폴리오/트렌드를 구조화한다.
4. 세 데이터를 연결해 조합 카드를 만든다.
5. 검색하면 추천 조합과 이유가 나온다.
```

---

```text
국가:

데이터 규모:
제조사 100개

유통사 100개
판매사 100개
트렌드 키워드 300개
조합 카드 100개
실제 테스트 거래 10개
```

---

## 3. 1주차: 구조 설계

작업:

```text
노드 정의
관계 타입 정의
스키마 확정
수집 템플릿 확정
매칭 점수 배점 확정
위키 페이지 템플릿 작성
```

산출물:

```text
온톨로지 문서
JSON 스키마
데이터 소스 목록
샘플 데이터
```

---

## 4. 2주차: 데이터 1차 투입

작업:

```text
제조사 100개 후보 수집
제품 500개 후보 수집
유통사 100개 후보 수집
판매사 100개 후보 수집
트렌드 키워드 300개 수집
```

산출물:

```text
제조사 Wiki 페이지
제품 Wiki 페이지
유통사 Wiki 페이지
판매사 Wiki 페이지
트렌드 노드
```

---

## 5. 3주차: 검색 프로토타입

작업:

```text
키워드 검색 구현
포트폴리오 유사 검색 구현
그래프 탐색 구현
매칭 점수 계산 구현
조합 카드 생성 구현
```

산출물:

```text
검색 CLI
샘플 조합 카드
매칭 점수 리포트
```

---

## 6. 4주차: 실제 매칭 테스트

작업:

```text
제조사 10개 선정
유통사 20개 선정
판매사 20개 선정
매칭 후보 30개 생성
샘플/미팅 제안 10건 진행
결과를 지식망에 반영
```

산출물:

```text
실제 매칭 결과표
성공/실패 사유
점수 보정안
2차 테스트 후보
```

---

## 7. 성공 기준

```text
검색하면 조합 카드가 나온다.
각 조합에는 추천 근거와 리스크가 있다.
추천 액션이 30일 테스트 형태로 제시된다.
실제 미팅/샘플 제안으로 연결된다.
테스트 결과가 다시 그래프에 반영된다.
```
