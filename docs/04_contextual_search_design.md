# 04. 맥락 기반 검색 설계

## 1. 검색의 목표

플로머스 검색은 업체명이나 상품명을 찾는 기능이 아니라 **거래 가능성이 높은 조합을 찾는 기능**이어야 한다.

```text
일반 검색:
“일본 유통사 찾아줘.”

플로머스 검색:
“이 제조사의 이 제품 스펙과 맞고,
도쿄권 물류가 가능하며,
향·헤어 트렌드 판매 경험이 있는
일본 유통사+판매사 조합을 찾아줘.”
```

---

## 2. 검색 유형

### 2.1 제조사 기준 검색

```text
이 제조사 제품 중 일본에 맞는 상품 찾아줘.
이 제조사의 상세페이지 기준으로 샤오홍수에 맞는 상품만 골라줘.
스펙상 선물형 판매가 가능한 제품 찾아줘.
MOQ가 낮고 일본 소형 판매사에 맞는 제조사 찾아줘.
```

### 2.2 유통사 기준 검색

```text
도쿄권에서 K-뷰티 위탁 유통 가능한 곳 찾아줘.
포트폴리오상 헤어·향 제품을 다뤄본 유통사 찾아줘.
한국 제조사와 일본 판매사 사이에 들어갈 수 있는 유통사 찾아줘.
```

### 2.3 판매사 기준 검색

```text
향·헤어·선물 키워드와 맞는 판매사 찾아줘.
샤오홍수에서 K-뷰티 후기형 콘텐츠를 잘 만들 수 있는 판매사 찾아줘.
포트폴리오상 감성 생활용품을 잘 파는 판매사 찾아줘.
```

### 2.4 조합 추천 검색

```text
이 헤어오일 제조사에 맞는 일본 유통사와 판매사 조합 추천해줘.
중국 샤오홍수 테스트에 맞는 제조사-판매사 조합 만들어줘.
상품 스펙, 유통 위치, 판매 트렌드까지 고려해서 5개 매칭 후보 뽑아줘.
```

---

## 3. 검색 엔진 구조

```text
1. 키워드 검색
정확한 회사명, 제품명, 사업자번호, 플랫폼명 검색

2. 벡터 검색
표현은 다르지만 의미가 비슷한 상품·포트폴리오·트렌드 검색

3. 그래프 검색
제조사→제품→유통사→판매사→트렌드 관계 탐색

4. 요약 검색
카테고리/국가/채널 단위의 시장 맥락 요약

5. 점수 검색
매칭 점수 기준 후보 정렬
```

---

## 4. 검색 처리 흐름

예시 질문:

```text
“손상모 헤어오일을 일본에 팔고 싶은데 적합한 조합 찾아줘.”
```

처리 흐름:

```text
1. 의도 파악
- 상품: 헤어오일
- 문제상황: 손상모
- 국가: 일본
- 목적: 제조사·유통사·판매사 조합 추천

2. 엔티티 검색
- 헤어오일 제품
- 손상모/향 지속 트렌드
- 일본 헤어케어 판매사
- 일본 뷰티 유통사

3. 그래프 확장
- 제조사 → 제품 → 스펙 → 트렌드
- 유통사 → 포트폴리오 → 위치 → 유통 방식
- 판매사 → 포트폴리오 → 채널 → 고객층

4. 점수 계산
- 제품 적합도
- 유통사 포트폴리오 적합도
- 위치/물류 적합도
- 판매사 포트폴리오 적합도
- 트렌드 적합도
- 리스크 감점

5. 조합 카드 생성
- 추천 조합
- 근거
- 리스크
- 다음 액션
```

---

## 5. 검색 결과 형식

```text
조합 카드 1

제조사:
ABC코스메틱

제품:
노워시 퍼퓸 헤어오일

유통사:
Tokyo Beauty Distribution

판매사:
Tokyo Beauty Select

대상 국가:
일본

대상 채널:
Instagram + BASE

매칭 점수:
82점

추천 근거:
- 제품 스펙이 손상모·향 지속 트렌드와 맞음
- 유통사는 도쿄권 뷰티 유통 포트폴리오 보유
- 판매사는 향·헤어 제품 콘텐츠 경험 있음
- 가격대가 일본 소형 뷰티 시장과 맞음

리스크:
- 향 취향 차이
- 일본어 성분 표기 필요
- 액체류 배송 조건 확인 필요

추천 액션:
- 샘플 20개 발송
- 일본어 상세페이지 제작
- KOC 5명 테스트
- BASE 30일 위탁 판매
```

## 6. 검색 품질 지표

```text
추천 조합 클릭률
미팅 전환율
샘플 발송 전환율
30일 테스트 진행률
본계약 전환율
재발주율
추천 실패 사유 분류율
사용자 피드백 반영률
```

검색 품질은 조회 수가 아니라 **거래 진행률**로 평가한다.
