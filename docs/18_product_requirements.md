# 18. MVP 제품 요구사항 PRD

## 1. 제품명

Flomers Commerce KG MVP

## 2. 목표

제조사 제품 상세/스펙, 유통사 포트폴리오/위치, 판매사 포트폴리오/트렌드를 연결해 **제조사 × 제품 × 유통사 × 판매사 조합 카드**를 생성하는 내부 검색 도구를 만든다.

---

## 3. 핵심 사용자

```text
플로머스 운영자
사업개발 담당자
데이터 리서처
매칭 담당자
```

외부 고객 포털은 MVP 이후에 만든다.

---

## 4. 핵심 기능

### F1. 데이터 입력

```text
제조사 등록
제품 등록
유통사 등록
판매사 등록
트렌드 등록
근거 등록
거래 결과 등록
```

### F2. 맥락 검색

```text
제품 기준 검색
유통사 기준 검색
판매사 기준 검색
국가/채널 기준 검색
트렌드 기준 검색
```

### F3. 조합 카드 생성

```text
제조사
제품
유통사
판매사
대상 국가
대상 채널
매칭 점수
추천 근거
리스크
다음 액션
```

### F4. 근거 추적

```text
모든 추천 근거에 source/evidence 연결
출처 신뢰도 표시
최신성 표시
```

### F5. 운영자 피드백

```text
적합/부적합
미팅 진행
샘플 발송
테스트 착수
본계약
재발주
실패 사유
```

---

## 5. 검색 예시

```text
“일본에서 향·헤어 트렌드에 맞는 한국 제조사-유통사-판매사 조합 찾아줘”
```

예상 출력:

```text
ABC코스메틱 × 노워시 퍼퓸 헤어오일 × Tokyo Beauty Distribution × Tokyo Beauty Select
점수: 92.1
추천: 강력 추천
액션: 샘플 20개 → 일본어 상세페이지 → BASE 30일 테스트
```

## 7. 비기능 요구사항

```text
근거 없는 추천 금지
데이터 신뢰도와 최신성 표시
중복 업체 병합 가능
수동 검수 상태 관리
검색 결과 재현 가능
개인정보/약관/robots 정책 준수
```

---

## 8. MVP 성공 기준

```text
제조사 100개 등록
제품 500개 등록
유통사 100개 등록
판매사 100개 등록
조합 카드 100개 생성
실제 미팅/샘플 제안 10건
30일 테스트 거래 3건 착수
```

---

