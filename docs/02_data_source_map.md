# 02. 데이터 소스 맵

## 1. 데이터 소스 전략

플로머스는 데이터를 다음 네 층으로 나누어 수집한다.

```text
1. 공개·공식 데이터: 후보 발굴과 실체 검증
2. 플랫폼 데이터: 수요, 가격, 리뷰, 트렌드 판단
3. 업체 제출 데이터: 거래 조건과 실행 가능성 판단
4. 플로머스 자체 거래 데이터: 매칭 정확도와 해자 형성
```

## 6. 데이터 신뢰도 등급

| 등급 | 데이터 유형 | 예시 |
|---:|---|---|
| 1 | 공개 웹 관찰 | 홈페이지 설명, SNS 공개 글 |
| 2 | 플랫폼 공개 데이터 | 상품 가격, 리뷰 수, 랭킹 |
| 3 | 정부·공공 API | 공장등록, 통신판매업, 무역통계 |
| 4 | 업체 제출 자료 | 카탈로그, 견적서, 인증서 |
| 5 | 플로머스 검수 자료 | 미팅 메모, 샘플 검수 |
| 6 | 테스트 거래 결과 | 주문, 반품, 리뷰, CS |
| 7 | 반복 거래 결과 | 재발주, 계약, 정산 완료 |

맥락 검색과 추천 점수는 이 신뢰도를 반영해야 한다.
