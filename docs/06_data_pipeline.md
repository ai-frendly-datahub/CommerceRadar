# 06. 데이터 파이프라인

## 1. 전체 구조

```text
수집
→ 정제
→ 엔티티 추출
→ 관계 추출
→ 위키 페이지 생성
→ 그래프 저장
→ 벡터 인덱싱
→ 검색/추천
→ 거래 결과 피드백
```

---

## 2. 제조사 수집 파이프라인

```text
1. 제조사 도메인 수집
2. robots.txt 확인
3. sitemap.xml 확인
4. 제품 목록 페이지 탐색
5. 제품 상세페이지 수집
6. 구조화 데이터 추출
7. 본문/이미지/스펙표 추출
8. PDF 카탈로그 추출
9. LLM으로 제품 스펙 정규화
10. 사람이 핵심 제품 검수
11. 제조사 Wiki 페이지 생성
```

추출 대상:

```text
JSON-LD Product
Microdata Product
OpenGraph title/description/image
제품명
제품 설명
이미지
가격 정보
브랜드
옵션
재고 여부
인증 문구
OEM/ODM 문구
```

---

## 3. 유통사 수집 파이프라인

```text
1. 유통사 도메인 수집
2. 회사소개/사업영역 페이지 수집
3. 취급 브랜드/포트폴리오 페이지 수집
4. 물류센터/지사 위치 추출
5. 거래처/납품 사례 추출
6. B2B 문의 유형 추출
7. 취급 카테고리 분류
8. 유통 방식 추론
9. 위치 기반 커버리지 생성
10. 유통사 Wiki 페이지 생성
```

우선 탐색 URL 패턴:

```text
/about
/company
/business
/brand
/portfolio
/distribution
/logistics
/partners
/client
/location
/contact
```

---

## 4. 판매사 수집 파이프라인

```text
1. 판매사 채널 URL 수집
2. 자사몰/플랫폼 상점 수집
3. 베스트셀러 상품 추출
4. 가격대 분석
5. 리뷰/평점 수집
6. 소셜 콘텐츠 수집
7. 콘텐츠 스타일 분류
8. 트렌드 키워드 매핑
9. 적합 상품 유형 추론
10. 판매사 Wiki 페이지 생성
```

판매사 채널 유형:

```text
검색형: 네이버, Rakuten, Amazon
콘텐츠형: Instagram, 샤오홍수, TikTok
라이브형: 더우인, 라이브커머스
커뮤니티형: 위챗, LINE, 카카오톡 채널
선물형: 카카오톡 선물하기, LINE Gift
굿즈/리셀형: Mercari, 팬덤몰, 인증형 리셀
```

---

## 5. 데이터 갱신 주기

| 주기 | 수집 대상 |
|---|---|
| 매일 | 플랫폼 랭킹, 핵심 키워드, 가격 변화, 환율 |
| 매주 | 신규 업체, KOC/KOL 후보, 리뷰/댓글 키워드 |
| 매월 | 온라인쇼핑동향, 수출입 통계, 공장등록, 통신판매사업자 |
| 분기 | 국가별 카테고리 성장률, 유통사 인터뷰, 판매사 포트폴리오 검수 |
| 연간 | METI EC 조사, 중국 연간 통계, 한국 연간 쇼핑동향, 전략 재분류 |

## 6. 데이터 품질 관리

```text
중복 업체 병합
회사명 정규화
주소 표준화
카테고리 표준화
HS코드 매핑
플랫폼명 표준화
가격 통화 변환
수집일/검증일 기록
신뢰도 점수 부여
```

---

## 7. 저장 계층

```text
관계형 DB:
업체, 상품, 수치 데이터, 거래 조건

그래프 DB:
제조사-제품-유통사-판매사-트렌드 관계

벡터 DB:
제품 상세페이지, 카탈로그, 미팅 메모, 리뷰, 콘텐츠

문서 저장소:
계약서, 인증서, 견적서, 카탈로그 원본
```
